# ADR-0006: 知识蒸馏为工作流收尾节点

- 状态：已接受
- 日期：2026-09-12

## 背景

任务过程中产生的决策、偏差、踩坑是宝贵知识，但依赖人工事后整理往往被遗漏。

## 决策

**知识蒸馏是工作流收尾节点**：reporting 节点按模板自动生成 Report.md（含决策与偏差、蒸馏新增知识），写入 playbook，人工只负责 review 后合入 spec/decisions。

## 理由

- 把知识回流固化为流程环节，而非个人义务，保证可持续沉淀。
- 自动产出降低人工负担，review 仍保留最终质量把关。

## 影响

- reporting 节点为闭环必需环节，写入失败不使任务失败（本地暂存并告警）。
- 报告模板见 SPEC 6.4。
