# ADR-0003: 仓库可见性划分

- 状态：已接受
- 日期：2026-09-12

## 背景

项目涉及两类产物：可公开的工具代码，以及含业务 spec、决策、任务报告的领域知识。二者可见性需求不同。

## 决策

**工具仓库（loopctl）公开；playbook 知识仓库私有**。loopctl 自身的开发 SPEC 与 ADR 存放于工具仓库（公开），业务侧 spec/ADR 存放于 playbook（私有）。

## 理由

- 工具代码与开发规范适合开源协作。
- 业务知识（需求背景、决策依据）可能含敏感信息，私有更安全。

## 影响

- 两个独立 git 仓库；各自独立的提交身份与忽略规则。
- playbook 不进入 loopctl 仓库，运行时通过配置指向其根目录。
